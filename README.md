# VantaCore — AI Runtime Security Control Plane (Frontend)

Interactive Web Console and Cinematic Landing Page for **VantaCore** — an AI Runtime Security Control Plane for autonomous, tool-using AI agents.

## 🚀 Live Demo
Deployed on GitHub Pages:
👉 **[https://ad069-rezero.github.io/VentaCore/](https://ad069-rezero.github.io/VentaCore/)**

---

## ✨ Features
- **Cinematic 3D Hero & Visualizations:** Three.js & React Three Fiber dynamic shaders, agent neural graph visualization, and interactive security posture matrix.
- **Operations Console:** Comprehensive real-time dashboard including:
  - System Health & Threat Overview
  - Agent Registry & Session Inspector
  - Security Events & Forensic Investigation Workflows
  - Attack Chain & Blast Radius Visualizer (powered by `@xyflow/react`)
  - Tool Governance & Sandboxed Connector Execution Controls
  - Automated Approval Center & Quarantine Vault
  - Policy Lifecycle & Audit Logging Explorer
- **Zero Backend Dependency for Demo:** Embedded mock data providers and realistic synthetic network latency simulation.

---

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4 + Motion + GSAP
- **3D & Graphs:** Three.js, React Three Fiber, React Flow (`@xyflow/react`), Recharts
- **Icons:** Lucide React
- **Routing:** React Router 7 (`HashRouter` for zero-configuration GitHub Pages compatibility)

## 📦 Local Development

```bash
# Install dependencies

# Build for production

# Preview production build locally
```
